# Verification

- Implement: Write the code to fulfill the requirement.
- Run the relevant checks: Execute tests, linters, or type checkers that validate the specific change.
- Inspect the resulting diff: Review the actual changes made to ensure they match intent and do not introduce regressions.
- Verify the requested behavior: Do not rely solely on automated checks if manual or empirical verification is required (e.g. running the app, checking the UI).
- Report concrete evidence: Always include command output, log snippets, or test results when confirming a task is complete. Never claim "done", "fixed", "working", or "complete" based only on code generation.
